

# PlotdotAI-Chat

This repository contains a chatbot system that extracts useful information from screenplays generated by the Plotdot AI platform.

## Installation

```
git clone https://github.com/zinebabercha/plotdotai-chat.git
cd plotdotai-chat
pip install pandas tqdm gliner google-generativeai langchain langchain-community faiss-cpu python-dotenv
```

## Pipeline Overview

The project consists of several sequential steps:

### Step 1: Named Entity Recognition (NER)

In the `step1_NER` folder:
1. Run the extraction script:
   ```
   python screenplay_ner.py --input_file film_script2.txt --output_dir extracted_entities
   ```
2. This produces several CSV files in the `extracted_entities` directory
3. The main outputs are `locations.csv` and `characters.csv`

### Step 2: NER Filtering

In the `step2_NER filtering` folder:
1. Run the Jupyter notebook
2. It takes `characters.csv` and `locations.csv` from Step 1 as inputs
3. Outputs filtered locations and characters CSV files

### Step 3: RAG System

In the `step3_NER result to RAG` folder:
1. Run the RAG script:
   ```
   python rag.py
   ```
2. This script uses:
   - Filtered locations and characters CSVs from Step 2
   - The original screenplay file (`film_script2.txt`)
3. Outputs:
   - `character_details.json`
   - `location_details.json` (Note: Currently only character JSON is available due to quota limitations. We'll need to regenerate this using the OpenAI API key)

### Step 4: Knowledge Graph Creation

In the `step4_knowledge graphs` folder:
1. Run the Jupyter notebook
2. It takes:
   - Filtered CSVs from Step 2
   - The screenplay script
3. Outputs:
   - HTML visualization
   - `relationships.csv`
4. Running the HTML file generates the visualization saved as `knowledge_graph.png`

## Fountain Format

The repository also includes a `fountain` folder for handling the Fountain screenplay format:
- Run the Jupyter notebook which uses `script.fountain` as input
